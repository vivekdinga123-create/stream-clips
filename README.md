# Stream Clips

Cloud-based YouTube livestream clipping app. Paste a livestream URL to generate vertical 9:16 highlight clips with captions and posting text.

## Deployment
Deploy this repository to Railway using its Dockerfile. Attach a persistent volume mounted at `/data` for generated media. The service should expose a health endpoint at `/health`.

## Status
Project scaffold is being prepared. Do not treat the app as deployed until a successful Railway deployment and public URL are confirmed.
