Stream Clips

Turn a YouTube livestream into vertical Shorts automatically.

YouTube authentication setup (one-time)

If YouTube blocks the server, upload a Netscape-format cookies.txt exported from your browser. Use a separate YouTube account if possible. Your cookie file is sent directly to this HTTPS app and stored on its private server volume. Never share it in chat or with anyone.
